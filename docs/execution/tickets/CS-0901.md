## 实现内容

### 1. `workers/training/rl/environment/` — §19.2 环境契约

- `contracts.py`：纯 pydantic（`extra="forbid"`，frozen）——
  `ENV_CONTRACT_VERSION=1`/`REWARD_CONTRACT_VERSION=1`；
  action union（discriminator `type`）：
  `ToolCallAction|FinalAnswerAction|AbstainAction|SwitchTaskAction|
  TerminateAction`（各带可选 `usage` token 上报）；
  `RlPolicyRef`（`kind` Literal `agent`——非 agent principal 在
  reset 即 `POLICY_NOT_AGENT`）；`RlTaskDef`（task_id/version/kind/
  messages/context_refs/subgroup/answerable/allowed_tools/budgets/
  **target**——`.public()`→`RlTaskPublic` 剥掉 target，policy
  永不可见）；`ReplayEntry`（tool/arguments/result/provenance，
  `.key()`=canonical `tool:canon(args)`）；`EvidenceSnapshot`
  （replay 表 + evidence_ids + `.digest()` + `.lookup()` +
  `.evidence_set()`）；`Observation`（policy-facing：status ∈
  ready|ok|unavailable|unknown_tool|denied|invalid_action|
  budget_exhausted|finished + 公共 task + result + `replay` 标记 +
  budgets_remaining + constraints + error——字段集固定，无
  reward/label 通道）；`RlCost`/`RlStep`/`EpisodeOutcome`/
  `EpisodeRecord`（版本/digest/seed/policy/逐步 trace/结局/
  totals/denied/invalid/unavailable/scope 计数/capability 标注）。
- `tools.py`：`EnvTool` Protocol；`FORBIDDEN_TOOLS` 动词表——
  物理实验族（run_physical_experiment/submit_lab_job/
  execute_lab_plan/schedule_experiment → `CAP_APPROVE_EXPERIMENT`）、
  导出/egress 族（export_data/request_export/export_artifact/
  upload_vault/sync_to_cloud/fetch_external → `CAP_APPROVE_EXPORT`）、
  标签族（read_eval_labels/hidden_targets/evaluation_labels →
  `CAP_READ_EVAL_LABELS`）、批准族（promote_model/
  approve_model_release/approve_experiment/approve_export）；
  `ReplayTool`（snapshot `.lookup()` 命中→结果+provenance，
  未命中→`ToolUnavailable`——**AT-0901-3 显式 unavailable，
  永不编造 oracle**）；`ComputationalTool`（本地纯计算；
  `validate_formulation` 校验组分名/去重/fraction∈(0,1]/Σ≈1.0）；
  `default_catalog()` 封闭集：search_evidence/
  get_evidence_record/summarize_task_evidence/
  request_calculation（replay）+ validate_formulation（计算）。
- `environment.py`：`ResearchRlEnvironment`——
  `reset(task_id, seed, evidence_snapshot, policy)` 钉死任务/
  版本/预算，校验快照覆盖 required_evidence_ids
  （`SNAPSHOT_INCOMPLETE`），返回 ready observation +
  constraints{allowed_action_types, allowed_tools=
  task∩policy 许可∩capability 有效授予, budgets}；
  `step(action)`：已结束→invalid →**环境侧**步骤/墙钟预算核查
  （clock 可注入，policy 不可伪造）→ 消耗 step → TypeAdapter
  校验（不合 schema→`invalid_action`+INVALID_ACTION，仍计预算）→
  token 用量记账→tool dispatch；dispatch 顺序：**先工具调用数预算
  →FORBIDDEN 动词（denied+ACTION_DENIED，任何 executor 未被咨询、
  compute 不扣——拒绝先于执行存在）→目录外（unknown_tool）→
  未授权（denied+TOOL_NOT_PERMITTED）→缺能力
  （denied+CAPABILITY_DENIED，server-side 经
  `effective_grants("agent",·)` 实算）→task_id 参数越界
  （denied+TASK_SCOPE_VIOLATION）→jsonschema 输入校验
  →compute 预扣→execute**；`ToolUnavailable`/异常→
  `unavailable`+UNAVAILABLE|TOOL_ERROR（工具错误是 observation，
  不是 reward 捷径）；成功→ok+`replay` 标记+provenance+
  组件输入{tool_valid, unique_call, compute_cost}；
  `switch_task` 恒 denied+TASK_PINNED（episode 钉死原任务）；
  `terminate(reason)` 幂等，产出 EpisodeRecord 且带 capability
  标注 `{dataStatus=fixture_only, scientificStatus=not_validated,
  execution="computational/replay only", heldOutSuiteAccess="none"}`。
- `loop.py`：`EpisodePolicy` Protocol + `run_episode` driver
  （reset→act→step→terminate，max_actions 兜底）。
- `policies.py`：构造器（tool_call/final/abstain/switch_task/
  terminate）+ `ScriptedPolicy`/`FunctionalPolicy` + `honest_policy`
  + **对抗电池**（duplicate_loop、cheap_validity_spam×12、
  always_abstain、fabricated_citation、unit_manipulator、
  lazy_guesser、selective_easy 只答易题、task_switcher、
  physical_experiment、export、label_probe）——供 §19.3
  要求的"每个捷径策略必须输给奖励套件"测试使用。

### 2. `workers/training/rl/rewards/` — §19.3 奖励服务

- `contracts.py`：冻结 vocabulary `GATE_IDS`（proper_termination/
  task_pinned/no_denied_actions/version_match/evidence_integrity）、
  `COMPONENT_IDS`（task_correctness/supported_evidence/
  valid_tool_execution/uncertainty_calibration/resource_efficiency）、
  `DEFAULT_WEIGHTS`；`GateOutcome`/`ComponentScore`（component+
  version+value+detail+provenance）/`RewardRecord`（版本回显+
  eligible+gates+components+scalar+task_completed+labels）/
  `RewardExpectation`/`RewardSuiteDef`/`RewardSuiteReport`
  （metrics{eligible_rate, task_completion, scalar_mean,
  component:<id>} + expectations pass/fail + passed + labels）。
- `service.py`：`RewardService`（**独立于 policy**——输入只有
  EpisodeRecord+RlTaskDef+EvidenceSnapshot）：
  - **gates（不参与性能权衡）**：proper_termination（outcome 记录）、
    task_pinned（scope_violations==0）、no_denied_actions
    （denied_attempts==0）、version_match（env/reward/task 版本+
    task_id+snapshot_digest 全对）、evidence_integrity
    （citations ⊆ snapshot.evidence_set——**伪造引用直接
    ineligible**）。
  - **组件（各自带 version+detail+provenance）**：
    task_correctness 二元（refusal 任务=拒绝∧未泄 forbidden_terms；
    unanswerable=abstained；answerable 按 expect 判，
    abstain=0——「永远拒答」不能赢）；supported_evidence=
    coverage×precision；valid_tool_execution=（ok ∧ unique_call）
    /attempted（**重复刷调用不计有效**；无尝试→None 不记 0）；
    uncertainty_calibration 行为化（该拒时拒、该答时答）；
    resource_efficiency=1−最差预算分数比。
  - scalar=非 None 组件加权均值；task_completed 独立于 scalar。
  - `evaluate_suite`：metrics+expectations→passed；报告带
    labels{separateFromEvaluation=True, ...}。
  - **禁用真相信号**：verbosity/引用数量/model 自报置信度
    均不参与——置信度字段被 `extra="forbid"` 直接拒入 action。
  - run 内版本冻结：`score_episode` 对
    task/contract/reward 版本错位 → `TASK_MISMATCH` 或
    version_match gate fail。
  - **held-out 套件不可作为奖励调用**：包内无
    promotion/evaluation_labels/hidden_targets import 路径
    （security 测试做源码级断言）。

## 已知限制 / 能力声明

- **capability 标注**：EpisodeRecord.capability 与 RewardRecord.
  labels 恒带 `dataStatus=fixture_only`、
  `scientificStatus=not_validated`、`execution="computational/replay
  only"`、`heldOutSuiteAccess="none"`、`separateFromEvaluation=True`
  ——fixture 证据与脚本策略不构成科学验证。
- **无真实推理后端**：电池全为脚本/函数策略；真实模型 policy 经
  `EpisodePolicy` Protocol + `usage` token 上报接入——真实化学
  结论须经科学评审（promotion gate 已在 CS-0803）。
- **确定性 replay**：replay 结果来自 `EvidenceSnapshot` 字节级
  fixture；「匹配」以 canonical JSON（tool+参数规范化）判，
  参数重排等价命中；新增 live 工具属 CS-0902 接线范围。
- **预算口径**：steps/tool_calls/墙钟/token/compute 独立硬上限，
  环境侧（非模型侧）记账；token 依据 policy 自报 usage——环境
  无 tokenizer 时不做重估，policy 可低报但被 max_steps/
  compute 间接约束（低报不换无限步骤）。
- **suite 判定为阈值制**：`evaluate_suite` 按 expectation min/max
  判 pass/fail；跨 suite 统计显著性检验未做（与 CS-0803 同口径，
  未知阈值不代填）。
- episode 持久化/任务来源/vault artifact 接线属 CS-0902；
  CS-0903（训练循环）与 CS-0506（U16）明确未做。
