## Limitations

- Task workspace sections are overview/candidates/decisions; the
  §22.1 research/experiments/evidence surfaces arrive with their
  domain tickets (experiments are P03+).
- ContractEditor edits the metrics draft only; constraint rows and
  freeze/review flows land when the review UI is built.
- Patch review UI buttons exist in the mutation layer; the review
  queue screen is a later workflow ticket.
- `beforeunload` covers browser-level navigation; in-app route
  interception for dirty-state is a follow-up.
- e2e uses an isolated DB on the dev postgres container; CI should
  prefer a dedicated ephemeral postgres.
