  the report identifies affected releases where they exist and
  never claims forgetting. `test_revoke_twice_conflicts` +
  `test_revoke_requires_reason` cover the command contract.

## Honest status / boundaries

- No dataset-snapshot or model-release tables exist yet — the
  impact report's `affectedDatasetIds`/`affectedModelReleaseIds`
  are structurally present and honestly empty; derived *artifacts*
  already flow through the same report today.
- `source_artifact_ids` is populated by callers (a derived
  artifact records what it drew from) — no automatic lineage
  inference is claimed.
- Marking `lineage_review=required` suspends reuse *visibly*; it
  does not itself block a future consumer — enforcement hooks
  arrive with the dataset/training surfaces that consume them.
- Quality report is computed at read time (always current); no
  materialized report table is kept.
