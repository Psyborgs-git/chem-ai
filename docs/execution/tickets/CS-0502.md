## 实现内容

### 1. 执行—批次—样品—测量持久化 `§6.3, §14.2`

- 迁移 `0018_lab_measurements` + 模型：
  - `LabExecution`：`plan_id`（可空 — 历史记录无计划）、
    `task_id`（可空 — 历史执行的作用域链）、`status`
    (`in_progress|completed|stopped`)、`historical` 标记、
    `actual`/`deviations`/`observations`、`closed_at`。
  - `LabBatch`（独立制备批次 — 复制单位）。
  - `LabSample`：`kind`∈`aliquot|timepoint|whole`。
  - `Measurement`：`method`、`repeat_type`∈`same_sample|
    independent_batch|independent_operator|timepoint`、
    `value_type`∈`numeric|interval|below_detection|
    above_quantification|ordinal|categorical|missing`、
    `value` JSONB（decimal 字符串 + unit）、`conditions`、
    `applicable`+`applicability_note`（合同适用性 ≠ 科学有用性）、
    `status`∈`proposed|accepted|rejected|superseded`、
    `pipeline_version`（处理管线溯源）、`superseded_by`。
  - `MeasurementAmendment`：reason+source+修正值 — 原行永不被
    覆盖（§14.2）。
  - 全部复合 `(workspace_id, id)` FK + 检查约束。

### 2. `LabMeasurementService` `domain/lab/measurements.py`

- `open_execution(planId)`：`CAP_EDIT_TASK` + 重新校验
  `LabPlanService.verify_release_approval` — stale/失效批准
  阻断开启（AT-0501-1 语义的下游延伸）。
- `import_historical(taskId, payload)`：历史记录 `historical=True`
  + status 仍为 `in_progress`→需正常关闭流程；**绝不伪造**
  追溯批准（§14.1）。
- `record_actuals`：实际物料/批次/工艺、deviations 列表、
  observations — 偏差记录即标记，合同适用性另行评估。
- `add_batch`/`add_sample`：仅 `in_progress` 可写。
- `record_measurement`：typed value 校验 —
  `numeric` 需 `value`(decimal string)+`unit`；`interval` 需
  `low/high/unit` 且 low≤high；censored(`below_detection`/
  `above_quantification`) 需 `limit`+`unit` — ** censored 不是 0**；
  `missing` 需 `reason`∈MISSING_REASONS。
- `review(decision)`：仅 `CAP_REVIEW_MEASUREMENT`（agent/viewer
  无此能力 — security 测试覆盖）。
- `set_applicability`：deviation 使测量对原合同不适用但保留
  科学价值 — 两个维度分离记录。
- `amend(reason, source, value)`：仅 accepted 可修正 → 创建
  amendment、原行 `status=superseded`+`superseded_by` —
  原值保留（AT-0502-3）；下游读到 superseded 标记。
- `replication_summary`：`independentBatches`=批次数；
  same_sample/timepoint 读数计为 observations 而非独立试验
  （AT-0502-1）。
- `compare_to_contract(metric)`：单位白名单 + 量纲分类
  （viscosity/mass/volume/fraction/temperature_diff 等）+
  显式换算表（`mPa·s↔Pa·s↔cP`、`%↔fraction`、`g↔kg`、
  `mL↔L`、时间单位）；绝对温度换算刻意排除（绝对值/温差歧义）。
  单位不兼容 / 无单位目标 / 非数值类型 → `inconclusive` +
  带 `action` 字段的 actionable finding，**绝不强制 pass/fail**
  （AT-0502-2）。质量↔体积无密度不换算；未知组成混合物不做
  分数换算（服务层无路径）。
- `close_execution`：关闭后全部写路径拒绝（CONFLICT）。
- 审计：`lab_execution.opened|.historical_imported|.closed`、
  `measurement.recorded|.reviewed|.amended|.applicability_set`。

### 4. 前端 `features/lab/results/`

- `ResultsPanel` 挂于 `/lab` 页 PlansPanel 之下：
  - approved plans → "open manual execution"；historical import
    表单明示 "never retrospectively approved"。
  - 执行卡片：status/historical 徽章 + MANUAL EXECUTION 标签、
    deviations 提示（合同适用性≠科学价值）、replication summary
    （independent batches / observations / repeat-type 计数）、
    actuals+deviations+observations 录入表单、批次→样品→测量
    三级展开、关闭执行。
  - 测量行：method/status/repeat_type 徽章、typed value 显示
    （censored 为 `< limit`/`> limit`，missing 带 reason）、
    `not contract-applicable` 徽章、`superseded` 徽章、
    amendment 链展示（reason + 修正值）、review accept/reject、
    applicability 切换、amend 表单（reason 必填 — UI 与后端
    双重保证）、contract comparison（inconclusive 时列出
    带 action 的 findings）。
  - 诚实性：无设备执行控件；历史执行永远带
    "historical import — not retrospectively approved" 徽章。

### 5. 并发修复（e2e 暴露的真实死锁）

LabPage 首次并发发出 2+ GraphQL 请求（taskPlans×2 +
taskExecutions）即挂死：每请求的 `authenticate_token` 心跳
`UPDATE auth_sessions.last_seen_at` 在请求事务内不提交 —
同 principal 的第二请求在该排他行锁上阻塞；同步 SQLAlchemy
调用运行在事件循环上 → B 的阻塞冻结整个 loop → A 的响应
永远无法序列化/提交 → 死锁（pg_stat_activity 观测：A
`idle in transaction` 持锁，B `Lock/transactionid` 等待）。

修复 `api/deps.py::build_context`：心跳 UPDATE 后立即
`db.commit()` — 锁持有时间从整个请求事务缩到微秒级；后续
工作在新事务中进行。修复后并发对与全页请求均 <200ms。

## 已知限制 / 能力声明

- 无设备执行端点；执行记录为手工录入（MANUAL EXECUTION 标签
  全页面可见）。
- 单位换算表为显式白名单 — 未列出的单位一律 inconclusive；
  质量↔体积需密度路径（本票未实现，不会静默换算）；绝对温度
  换算刻意排除。
- amendment 链在 UI 以 reason+value 列表展示；amendment 本身的
  review 工作流（修正的二次审批）可在后续收紧。
- 并发修复只解决了 auth 行锁路径 — 同步解析器在事件循环上
  阻塞慢查询仍是已知架构限制（如需，后续可将 GraphQL 执行
  移入 threadpool）。
- 软件验收 ≠ 科学验证：fixture 数据证明不可变修正/复制口径/
  单位安全语义，不构成对任何真实测量方法学的认可。
