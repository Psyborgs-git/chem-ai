## Acceptance evidence

- **AT-0302-1** — `ambiguous imported fields show flags and stay
  proposed`: seeded CSV import → `5%` row shows `percent literal —
  verify basis`, bare numeric shows `unit unresolved`, status stays
  `proposed`, never `accepted`. Service-level: `promote_record`
  yields a `proposed` claim (TestPromotionKeepsAmbiguityVisible).
- **AT-0302-2** — `test_contradicting_claims_both_remain_accepted_
  and_visible`: two accepted claims with different conditions linked
  `contradicts`; both remain `accepted`, conditions intact, link
  query returns the edge; linking is idempotent; kinds stay
  distinct; agent principals denied review and linking.
- **AT-0302-3** — `promoted claim shows the exact source locator`:
  promoted record → `/evidence` card cites `row 1, col 1` —
  the exact import locator. Service-level: claim carries
  `locator["cell"] == "B2"` + `original_text == "0.05"`.

## Honest status / boundaries

- Record review is steward-level (`manage_sources`); claim review is
  reviewer-level (`review_science`), human-only — matching the
  extraction/science separation in §9–§10.
- `imports.artifactImport` takes the raw artifact uuid (artifacts
  are vault records, not Relay nodes); dedup returns
  `deduplicated: true`.
- Claim promotion keeps the record's locator verbatim; structured
  statement parsing is a later-ticket concern.
