# CS-0401 — Integrate queue and authoritative Run records

**Status:** completed
**Phase:** P04 · **Owner:** runtime

## Changed files

- `services/studio-api/src/studio/persistence/models.py` — `Run`
  (authoritative execution record: kind, status, bounded `request`
  JSON + digest, attempt counters, lifecycle timestamps, error,
  result summary) and `RunAttempt` (attempt number unique per run,
  `external_id` unique per workspace, queue name, worker id,
  callbacks log).
- `services/studio-api/migrations/versions/0013_runs.py` — both
  tables with the full §7.3 status enums as check constraints and
  composite scoped FKs.
- `services/studio-api/src/studio/domain/runs/queue.py` —
  `RunService`: `request` (capability `request_compute`, request
  capped at 4 KB of canonical JSON — scoped IDs + bounded metadata
  only), `enqueue` (creates attempt + `run.attempt.enqueued`
  outbox event with an IDs-only payload in the same transaction),
  `accept_attempt` (worker-side idempotent bind of `external_id`),
  `start_attempt` / `complete_attempt` / `fail_attempt` /
  `timeout_attempt`, `request_cancel` / `confirm_cancelled`, and
  `reconcile` (heartbeat-expired attempts → `interrupted`, policy
  requeue as a NEW attempt). All status changes are CAS through a
  transition map; terminal statuses admit no outgoing transition —
  late callbacks are recorded on `attempt.callbacks` with
  `applied: false` and never mutate state. Every mutating method
  flushes before returning.
- `workers/common/queue.py` — Procrastinate bridge [S05]:
  `make_app` (in-memory connector for tests/dev; production wires
  a real Psycopg connector), `defer_attempt` returning the queue
  job id persisted as `external_id`, `AttemptRunner` (accept →
  start → injected executor → complete/fail), and
  `TransientInfraError` — the only executor exception eligible for
  bounded retry (§13.4).
- `services/studio-api/tests/integration/test_run_queue.py`.

## Acceptance evidence

- **AT-0401-1** — `test_duplicate_delivery_one_logical_run`:
  one `run.attempt.enqueued` event carrying only
  `{runId, attemptId, kind, queue}`; the attempt is deferred onto a

  boundary handles the delivery twice — same attempt row, executor
  invoked exactly once, `external_id` bound once.
  `test_accept_rejects_conflicting_external_id` (a second job id is
  CONFLICT, never a second attempt) and
  `test_outbox_delivery_ledger_dedupes` (the dedupe ledger itself).
- **AT-0401-2** — `test_dead_worker_reconciled_not_succeeded`:
  a running attempt goes silent; `reconcile` marks the attempt
  `interrupted`, the run `interrupted`, audits `run.interrupted`,
  and requeues attempt 2 under policy — the run is queued again,
  never reported succeeded. `test_interrupted_run_can_cancel`
  covers the interrupted → cancelled path.
- **AT-0401-3** —
  `test_late_success_cannot_overwrite_cancellation`: queued →
  running → cancel_requested → cancelled; a late success callback
  leaves the run `cancelled`, `result_summary` null, and the
  callback preserved on the attempt with `applied: false`.
  `test_terminal_run_rejects_late_failure_and_success` covers the
  mirror direction.
- Supporting: `test_request_bounded_metadata` (oversized run

  `test_transient_failure_requeues_under_policy` (classified

## Honest status / boundaries

- The queue bridge uses Procrastinate primitives with real defer +
  job-id semantics. The production connector (Psycopg DSN wiring)
  and a long-running worker process are not yet installed — the
  in-process `AttemptRunner` boundary is what tests exercise, and
  no scientific executor exists yet (engine adapters land in later
  P04 tickets; a missing executor fails the attempt `no_executor`,
  never simulates success).
- `reconcile` is driven by callers with a staleness threshold;
  there is no background scheduler yet. Cancellation termination
  is confirmed explicitly (`confirm_cancelled`) — the API never
  claims children stopped on acknowledgment alone (§7.3).
- Run records are service-layer only; no GraphQL/REST surface is
  exposed in this ticket (not in write scope).
