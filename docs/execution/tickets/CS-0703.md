## 实现内容

### 1. `packages/engine-adapters/analytics/` — 纯 stdlib 在进程内适配器

无任何科学包依赖（无 numpy/scipy）——所有数值处理为纯 Python
stdlib 实现，按票据要求 "stdlib/simple numerics"。

- `contracts.py`：纯 pydantic 契约（`extra="forbid"`, `frozen`）。
  `ADAPTER_VERSION="analytics-adapter/v1"`；
  `SUPPORTED_FORMATS={"jcamp-dx":"jcampdx-reader/v1","csv-xy":"csvxy-reader/v1"}`；
  `UNDECLARED_UNIT="undeclared"` 哨兵——csv-xy 文件本身不携带单位，
  单位必须经 `IngestSpec` 显式声明，未声明即拒绝比较；
  `ANALYTICAL_METHODS=("infrared","uv_vis","raman","nmr_1h")`；
  三个钉版变换 `baseline-offset/v1`、`minmax-normalize/v1`、
  `moving-average/v1`；`SIMILARITY_LIMITS` 四元组解释上限；
  `MAX_POINTS=1_000_000`、`MIN_ALIGNED_POINTS=8`、
  `MAX_RESAMPLE_POINTS=65_536`、`MAX_WINDOW=101`。
- `InstrumentContext`/`CalibrationContext`/`SampleContext`（
  `sample_id` 可空字符串，服务层解析为 LabSample 链接）；
  `IngestSpec{schema_version,method,label?,x_unit,y_unit,instrument,
  calibration,sample,preprocessing≤8}` + `digest()`；
  `CompareSpec{similarity{algorithm,range}}` + `digest()`；
  `SpectrumTrace(x,y,units)` 与 `ScopedSimilarity{algorithm,
  algorithm_version,value,scope,interpretation_limits,adapter_version,
  scientific_status="not_composition_evidence"}`——`scientific_status`
  是 Literal 常量，不可被调用方覆盖。

- `formats.py`：内容嗅探 `sniff_format`（JCAMP data-class LDR 在
  前 4096 字符、csv-xy 需两行数字分隔行；扩展名仅是提示）；
  `detect` 对不识别的格式返回 `None`——**绝不猜测解析**。
  JCAMP-DR 读器支持 AFFN `(X..Y)`、`(XY..XY)` 峰表与 `(X++(Y..Y))`
  （DELTAX 或 FIRSTX/LASTX/NPOINTS 推导）；SQUEEZED/DIFDUP 等压缩
  token → `ANALYTICS_UNSUPPORTED_ENCODING`；`XFACTOR/YFACTOR`
  应用；`NPOINTS` 校验；`##XUNITS` 必需。csv-xy 自动检测分隔符、
  跳过 `#`/`;`/`//` 前导注释（记录为 `metadata.preamble`）、严格
  两列、单位 = `UNDECLARED_UNIT`。`_finalize` 统一按 x 升序排序
  （记 warning）、拒重复 x 与非有限值。

- `transforms.py`：`apply_preprocessing` 返回 `(trace, [TransformRecord])`
  ——每步都带 `version` 与生效参数落库；`align` 在共享重叠区间内
  均匀网格重采样（`resample-linear/v1`）；`crop_to_range` 记录实际
  生效边界（请求范围向数据网格吸附，非声称的范围）。
- `similarity.py`：`cosine-similarity/v1` / `pearson-correlation/v1`；
  零范数 → `ANALYTICS_DEGENERATE_TRANSFORM`（常量谱无法
  pearson，如实报错而非编造）。
- `adapter.py`：`capability()` 报告 `available_tested`（两格式），
  `scientific_status=not_validated`；`compare` 拒绝跨 method
  （`ANALYTICS_METHOD_MISMATCH`）、跨单位（`ANALYTICS_UNIT_MISMATCH`）、
  `undeclared` 单位；返回 `ComparisonResult{similarity,transform={
  preprocessing:{left,right},alignment}}`——变换链随结果同行。

### 3. 服务端接线 `domain/chemistry/analytics.py` + GraphQL

- `AnalyticsService.ingest`：`user` 主体 +
  `CAP_EDIT_TASK`+`CAP_MANAGE_SOURCES`（server-side 检查）；
  artifact 必须 `upload_state="committed"` 且 `source_kind∈
  {upload,import}`；`detect→None` → 存行 `interpretation_state=
  "unsupported"`、`source_format=None`、无 processed artifact
  ——原始字节留 vault，**不猜解析**；支持格式 → 解析 →
  `_check_units`（`UNDECLARED` 以声明单位填补；文件单位与声明
  冲突 → `VALIDATION`）→ 预处理 → 派生 JSON artifact
  （`source_kind="derived"` + `source_artifact_ids` 谱系）→
  `processed` 行。幂等：`creation_key` + task 行锁 +
  `spec_digest` 不匹配 → `IDEMPOTENCY_MISMATCH`。
- `AnalyticsService.compare`：两序列须同 task、同 method、同
  x_unit、皆 `processed`；重采样对齐 → `ScopedSimilarity` 落
  `row.similarity` + 完整变换链落 `row.transform` + 派生
  result artifact。
- `sample_id` 解析为 LabSample 链接（仅 uuid 且在 ws 内）；
  `series_state`/`comparison_state` manifest 输出 camelCase
  （seriesId/taskId/method/sampleId/instrument/calibration/
  sourceFormat/interpretationState/rawArtifactId/processedArtifactId/
  transform/detail；comparison: similarity/transform/resultArtifactId）。
- GraphQL：`AnalyticalIngestInput`/`AnalyticalCompareInput`/
  `AnalyticalResult{task,errors,client_mutation_id}`，命名空间
  mutation `analytical{ingest,compare}`（镜像 `optimization`
  模式）；Task 类型新增 `analyticalSeries`/`analyticalComparisons`
  字段；`capabilities.py` 增 `engines.analytics` 块
  （`available`，detail 列格式 + `scientific_status=not_validated`）。
- `pyproject.toml`：wheel packages + ruff `src` + mypy 纳入
  `engine_adapter_analytics`。`packages/contracts/schema.graphql`
  已重新生成。

## 已知限制 / 能力声明

- **capability 标注**（§16.1）：两格式均为 `available_tested`；
  `scientific_status` 恒为 `not_validated`——fixture 处理仅证明
  管线可用性，不构成科学验证。`ScopedSimilarity.scientific_status`
  硬编码为 `not_composition_evidence`，调用方无法覆盖。
- 相似度是**有作用域的**：值仅在记录的
  algorithm/version/range/units/aligned_points 下有效；UI 显示
  scope + 全部 interpretation_limits，不折叠为单一百分比，
  不主张完整组成同一性。
- JCAMP 覆盖 AFFN `(X..Y)`/`(XY..XY)`/`(X++(Y..Y))`；SQUEEZED/
  DIFDUP/PAC 等压缩表 → `ANALYTICS_UNSUPPORTED_ENCODING`，
  显式拒绝而非猜测。其他 vendor 格式（spc/jdx 扩展等）走
  `detect=None` → unsupported 行。
- csv-xy 单位恒 `undeclared`，必须经 IngestSpec 声明；声明单位
  与文件单位冲突时报错而非覆盖。
- U05（外部仪器输入）为可选集成，未阻塞本票据；真实仪器
  fixture 需后续任务提供。
- RL/P08+、CS-0506 超出范围。
