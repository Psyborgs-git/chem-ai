## 实现内容

### 0. 方法选择（先端点、再参数、后方法 — §16.3 顺序）

- **端点**: `equilibrium_miscibility`——二元液相在指定温度下是否分相，
  以及分相时以组分 0 摩尔分数表示的、受网格分辨率限制的互溶间隙。
- **方法比选**: 原版 UNIFAC（VLE 拟合表）在 298.15 K 下对
  水+1-丁醇预测*完全互溶*——对一个有文献记载的 LLE 体系给出定性
  错误答案 → 否决；LAMMPS 需逐组分力场且预算大 → 会逼出"猜参数"，
  禁止。**选用 UNIFAC-LLE**（LLEUFSG/LLEUFIP，
  Magnussen/Rasmussen/Fredenslund 1981，参数本身即用 LLE 数据回归，
  与端点同族）；同体系预测分相、间隙 [0.534, 0.981] 对文献 [0.5, 0.98]。
- **方法记录**: `docs/science/methods/unifac-lle-miscibility-screen-v1.md`
  （名称、版本、必需参数、有效域、批准基准、局限性，含 model_context
  字段清单与 proxy↔产品性能结构化分离约定）。

### 1. `packages/engine-adapters/materials/` — 钉版适配器（不进核心科学依赖）

- `contracts.py`：纯 pydantic 契约，**无任何科学包 import**。
  `THERMO_VERSION=0.6.1`、`ADAPTER_VERSION=materials-adapter/v1`、
  schema `materials_lle_job/v1`、method `unifac-lle-miscibility-screen/v1`。
- `MaterialsJobSpec`：`extra="forbid"`；恰好两个 `Component{name,
  unifac_groups{subgroup_id:count}}`（子基团分解即参数集——无法用
  LLEUFSG 表达的组分如聚合物分布/盐/未知配方 = 不支持输入，绝不找
  替代分子）；`temperature_k ∈ [278.15, 333.15]`（表回归带，不外推）；
  `grid_points ∈ [101,4001]` 默认 801；`ResourceEnvelope` 界
  `wall≤600s / mem≤4096MiB / cores≤4`；`digest()` 内容寻址。
- `validation.py`：内嵌已发布的 LLEUFSG 子基团表（57 子基团/32 主基团）
  与 LLEUFIP 有向主基团对覆盖表——**thermo 对缺失相互作用对会静默
  填零**，宿主侧与容器侧都先查覆盖再算：未知子基团 →
  `ENGINE_UNSUPPORTED_INPUT`；无回归对 → `MISSING_PARAMETERS`
  （AT-0702-1，绝不填零）。`build_job_payload` 生成持久化 job 字节。
- 数值：逐网格点 `UNIFAC.from_subgroups(T, xs, chemgroups, subgroups=
  LLEUFSG, interaction_data=LLEUFIP)` → `gammas()` →
  `g_mix/RT = Σ x_i ln(x_i·γ_i)` → **下凸包判据**：曲面高出凸包弦
  即分相；间隙端点 = 包触点（确定性、无迭代收敛问题）。
- `adapter.py`：容器内校验 thermo 版本钉扎、persisted payload 与 spec
  归一化漂移比对、对**活的** LLEUFIP/LLEUFSG 表再查覆盖（内嵌表与
  发布数据一致时冗余，漂移时兜底）；结果 manifest 带
  `model_context{model, parameter_table, assumptions, boundary_conditions,
  ensemble, sampling{grid_points,resolution}, convergence, calibration}`；
  `supports_endpoints`/`does_not_establish`/
  `evidence_class="computed_equilibrium_proxy"` 结构化字段——
  equilibrium 分相代理与储存/乳液/动力学稳定性及产品性能**结构上
  分离**（AT-0702-2），`scientific_status` 恒 `not_validated`。
- `validation.evaluate_endpoint`：端点评定返回类型化裁决
  `within_proxy_scope` / `not_established(basis=proxy_scope_gap)`——
  判定逻辑是 typed record，不是免责字符串。
- `capability()`：按镜像实测报告 `available_tested`/
  `installed_unverified`/`not_installed`，并携带方法的
  endpoint/domain/benchmark/limitations 原文（AT-0702-3）。

### 2. `workers/chemistry/materials/` — 隔离运行器（镜像 `workers/chemistry/quantum/`）

- `Dockerfile`：`python:3.12-slim` 基座（全 pip wheel 即可），
  `requirements.lock` 冻结 thermo 0.6.1 及其完整传递闭包
  （chemicals 1.5.2 / fluids 1.3.1 / scipy 1.18.1 / pandas 3.0.6 /
  numpy 2.5.3 / python-dateutil / six + pydantic 2.13.5）。
  镜像 `chem-studio-materials:0.6.1-v1`。
- `runner.py`：读 ≤2MB `request.json{spec,input}` → 落盘
  `input.job.json` + `result.json` → stdout 仅 JSON；
  `--capability` 探针模式；`EngineFailure`/`MemoryError` →
  `{code,message}` + exit 2；其余异常 → 脱敏
  `ENGINE_UNSUPPORTED_INPUT`。
- `runtime.py`：`IsolatedMaterials.compute` 经 `ContainerBackend`：
  `--network none`、只读根、UID 65534、`cap-drop ALL`、
  no-new-privileges、tmpfs /tmp、scratch `chmod 0777`、
  `ExecLimits{wall=cpu=spec.resources.wall_seconds, memory, pids=64,
  output=2MB, files=64MB}`；cancel → `RUN_CANCELLED`、超时 →
  `RUN_TIMEOUT`、非零退出/无输出 → `ENGINE_UNAVAILABLE` 或容器内
  JSON `{code}`；`available()`/`capability()` = 镜像存在 + 容器内探针。

### 3. 服务端接线 `domain/chemistry/materials.py` + `api/capabilities.py`

- `MaterialsService.request`：profile 关 → `ENGINE_UNAVAILABLE`；
  spec/覆盖校验失败 → run 以 `blocked(reason="insufficient_inputs",
  detail={capability, detail, policy})` 落库——**缺参即 blocked，零
  artifact/attempt**。合法请求：job 字节先持久化（vault 私有，
  `source_kind="derived"`, `upload_state="committed"`）再建 run；
  镜像缺席 → `blocked("engine_not_installed")`；admission 按资源包络
  准入（queue `materials`）。
- `execute`：vault 取回 persisted payload → 重建 spec → isolated
  compute → 结果 artifact 持久化 → `usable` 才 `complete_attempt`；
  `missing_parameters`/`engine_failure`/`malformed_result` →
  `fail_attempt(retryable=False)`；cancel/timeout 如实映射；run
  summary 携带 `evidence_class`/`supports_endpoints`/
  `does_not_establish`。
- `assess_endpoint`（AT-0702-2 服务表面）：对
  `storage_stability`/`emulsion_stability`/`kinetic_stability`/
  `product_performance` 恒返回 `not_established`；仅
  `equilibrium_miscibility` 返回 `within_proxy_scope`；无可用输出
  → `not_evaluated`。
- `capabilities.py`：`profile_materials`（`STUDIO_PROFILE_MATERIALS`）；
  `profiles.materials` 走真实容器探针；`engines.materials` 块报告
  available/degraded/unavailable + **逐方法 benchmark/domain/
  limitations 卡片**（AT-0702-3）。
- GraphQL `ProfileCapabilities` 增 `materials` 字段；
  `packages/contracts/schema.graphql` 已同步再生成。

## 已知限制 / 能力声明

- **capability 标注**（§16.1）：方法 `unifac-lle-miscibility-screen/v1`
  = `available_tested`（本票据实测）；镜像缺席 = `engine_not_installed`
  blocked；输入缺参/无回归对/未知子基团 = `insufficient_inputs`
  blocked / `MISSING_PARAMETERS` / `ENGINE_UNSUPPORTED_INPUT`；
  profile 关 = `disabled`。`scientific_status` 恒 `not_validated`——
  基准断言仅证明**安装可用性与定性文献行为复现**，不构成科学验证。
- **基准的性质**：文献记载的定性 LLE 行为断言（水+丁醇分相、
  水+乙醇/甲醇、苯+己烷互溶）+ 数值间隙端的*实现回归锁*
  （±0.08 容差），非实验拟合。
- **方法只答一个端点**：equilibrium_miscibility；储存/乳液/动力学
  稳定性、粘附、耐久、任何产品性能主张在结构上不可由本结果建立
  （typed verdict，非免责语）。
- **网格判据分辨率**：间隙端点精确到网格间距（默认 801 点 ≈1.25e-3），
  manifest `sampling.gap_bounds_resolution` 如实报告。
- **RUN_TIMEOUT 未做实跑覆盖**：本方法即使在最大 4001 点网格下也
  <1s 完成，小于资源包络最小 wall（1s）——不伪造慢引擎；timed_out
  → RUN_TIMEOUT 映射在集成层以服务边界测试覆盖（与 CS-0701 同一
  executor 路径）。
- **RUN_CANCELLED 实跑覆盖**：launch 前已置位的取消事件 →
  `RUN_CANCELLED`，不提交结果。
- 内嵌 LLEUFSG/LLEUFIP 表为**公开化学数据**（与 thermo 发布版一致的
  参数表镜像，非模型训练数据）；容器内对活表再查覆盖，漂移即失败。
- U03/U05/U14 未知：本票据为 optional-integration，core 不因缺失
  外部输入而阻塞；缺失输入恒产出 blocked capability。
- `make test-e2e`、训练/RL 超出范围（P08+ 禁止）。
