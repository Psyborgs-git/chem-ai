## 实现内容

### 1. `packages/engine-adapters/baybe/` — 有界版本化适配器（不进核心）

- `contracts.py`：`CampaignSpec`/`Recommendation` pydantic 契约 —
  `ADAPTER_VERSION`/`ENGINE_VERSION`/`IDENTITY_VERSION` 固定；
  显式映射连续界/离散数值/类别参数与 `gte|lte|between|eq` 目标方向；
  `spec.digest()` 内容寻址。
- `validation.py`：参数级独立校验（精确十进制、离散成员关系、
  连续绝对距离 1e-6、线性等式/混合物总量 1e-6，**不复归一化**）。
- `adapter.py`：冷启动 `RandomRecommender`（如实记录）；声明观测数后
  `TwoPhaseMetaRecommender`→`BotorchRecommender(qLogNoisyExpectedImprovement)`；
  混合物以精确十进制枚举 → `SearchSpace.from_dataframe`，连续线性约束为
  `ContinuousLinearConstraint(interpoint=False)`；
  对 BayBE **不可信输出**执行 `validate_batch` —— 越界/违约束建议被拒；
  `requested_batch_size` 修复：批次语义不受内部可行性收缩影响。
- 失败关闭：hybrid 空间、cardinality、interpoint/批次约束、多目标、
  molar/volume 混合物、custom descriptors、未知字段 →
  `ENGINE_UNSUPPORTED_INPUT` / `exhausted|no_feasible_suggestions`，
  无静默降维或重参数化。
- 无 BayBE `to_json`/pickle —— replay 为受版本保护的 JSON manifest
  （seed、recommender 配置、观测、保留建议身份）。

### 2. `workers/optimization/` — 隔离运行器

- `campaign.py`：纯内存 `Campaign`/`ReplayState` —— 生命周期
  （pending→observed|cancelled|failed）、幂等 creation_key、
  保留建议身份去重、终端实验不可变；取消/失败必须给 reason，
  **绝不伪造零值观测**。
- `runner.py` + `runtime.py` + `Dockerfile` + `requirements.lock`：
  `chem-studio-baybe:0.15.0-v1` 容器，`--network none`、只读根、
  非 root、固定线程/内存/进程上限、2MB 请求上限、120s 超时；
  错误仅返回 `{code,message}`（不泄漏配方 traceback）。

### 3. 服务端 `domain/learning/optimization.py` + 迁移 `0021`

- `optimization_campaigns`：workspace+task 作用域、冻结 contract
  revision 钉扎、`revision` 乐观并发、`creation_key` 幂等、
  `commands` 幂等键账本。
- DB 触发器 `optimization_definition_immutable`：定义列（scope、
  contract、definition、digest、creation_key、created_by）不可变。
- 每次请求重校验：任务 active、contract 未变、逐观测重跑
  `prepare_run` + snapshot 权利/来源 hash —— 漂移即
  `EVAL_CONTAMINATION`；撤销/修订阻断而非静默重拟合。
- 观测链接要求经审查、适用、numeric measurement，位于冻结的
  `property_prediction` snapshot 且 `rightsTraining ∈ {owned,allowed}`；
  `conditions.actual.optimization` 须含 `campaignId`/`experimentId`/
  `parameters`/完全一致的 `context`。缺测/审查外/失败标签≠0。
- 权限：`review_science`/`manage_models` 方才允许冻结定义与生命周期决策；
  非用户主体（agent/服务）不得记录生命周期状态。

### 4. GraphQL + Studio Web

- `schema.py`/`types.py`：`optimization.create`/`optimization.command`
  mutations + `Task.optimizationCampaigns`；`capabilities.py` 门控
  `profile_optimization`。
- `features/optimization/`：`OptimizationPanel` + relay operations —
  `retryKey(ref, payload)` 幂等键（相同输入重试复用键；
  输入变化才重发）；错误提示如实声明“请求结果未知”而非
  假报失败；`TaskWorkspace` 挂载面板。
- 合成 fixture `fixtures/synthetic/optimization-campaign.json` —
  标注 `fixture_only`，非科学证据。
