## Honest status / boundaries

- Token estimation is a documented ~4-chars-per-token approximation
  recorded on the manifest; no model tokenizer is wired.
- "Active approvals and runs" are not yet manifest items — the
  approval/run models predate this layer; they join when those
  surfaces land in later phases.
- Session messages are a persisted layer; there is no model turn
  execution yet (agent turns arrive with the tool-policy work).
- Summaries are created via mutation for provenance plumbing; an
  LLM generator is out of scope — `generator` records whatever
  produced the text (tests use "deterministic"/"test").
- Prior-session history items appear only after a session ends.
