## 实现内容(按 ticket 顺序)

### AT-1101-1 [security] 恶意文档 + 跨作用域 ID → 拒绝越权动作与暴露

`test_cs1101_loaders.py`(27 tests)+ `test_cs1101_boundaries.py`(32 tests)对每个真实攻击面做端到端攻击,而非单测罗列:

- **装载器/隔离管线**:zip/tar 成员穿越(绝对、`..`、反斜杠、symlink)、成员数/单成员/总解压/压缩比上限、空 zip EOCD 逃逸、polyglot(PDF+ZIP)、docx/xlsx 宏类成员任意路径段、xlsx 公式、嵌入 prompt-injection 片段、超大输入、解析超时真实杀进程、NUL 字节(嗅探窗内→binary,窗外→持久化剥除+旗标)。
- **边界**:loopback Host/Origin 欺骗、非安全方法 Origin 策略、会话 cookie SameSite、伪造会话拒绝;Relay global id / artifact / run / batch id 跨 workspace 穿越全部 → null/404 与“不存在”不可区分;keyset 游标跨 kind/scope → VALIDATION;GraphQL/SQL 注入走参数化,恶意串只作数据落库;page 上限。
- **工件/保险库**:staging→vault 全流程;storage key `..\`、前置 `/`、NUL、`.`/`..`/空段全部拒绝;`C:\x` 类键在 POSIX 下被收敛(受限)或拒绝。
- **Worker/容器边界**:`SubprocessBackend` 剖面如实声明 `argv_only_no_shell`/`env_scrubbed`/`network_denied=False`;不满足契约的后端驱动真实 `AttemptExecutor` → `profile_unavailable` 类型化失败;`_write_inputs` 仅 basename;stderr 尾部控制字符映射 ``(终端注入防护)。
- **审计/出口**:嵌套任意深度的敏感键(token/password/secret…)丢弃、NUL 剥除;全仓库出站导入扫描从 `services/` 扩到 `workers/`+`infra/`——唯一网络客户端仍是 `workers/inference/runtime.py` 的硬编码 loopback urllib。

### 发现并修复的缺陷(回归测试全程攻击验证)

1. 空 zip(EOCD `PK\x05\x06`)逃逸类型识别 → `detect_type` 认全 ZIP magic 组。
2. NUL 字节落在 4KiB 嗅探窗外 → 写库 psycopg DataError 崩溃(DoS)→ `pg_clean` 边界剥除 + `nul_scrubbed` 旗标;`original_name` 同样校验。
3. 活性内容检查仅看 basename → `xl/macrosheets/` 等嵌段逃逸 → 全路径段检查。
4. Vault/归档成员反斜杠穿越(Windows 风格 `..\`)→ 归一化为 `/` 再判段。
5. 审计敏感键只丢顶层 → 嵌套 `{"envelope":{"token":…}}` 泄露 → 递归丢弃。
6. stderr 尾部 ANSI/NUL 注入进 run.error/审计 → 映射 ``。
7. `profile_unavailable` 路径撞 `queued→failed` 非法迁移 → executor 先 accept+start 再 typed fail(attempt 如实记“被捡起后拒”)。
8. 撤消后两条复活通道:`index_batch` 不过滤 `rejected` 记录、`import_artifact` 不查 `review_state` → 均加闸。
