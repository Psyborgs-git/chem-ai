## 实现内容

### 1. 模型 + 迁移 `0020_dataset_snapshots`

`dataset_snapshots`：purpose（`property_prediction|extraction_correction|
assistant_sft|preference_pairs|rl_tasks`）、name、task_id（可空）、
manifest JSONB、digest（canonical JSON sha256）、
state（`draft|frozen`）、created_by/frozen_by/frozen_at。

### 2. 服务 `domain/learning/datasets.py`

- `build(purpose, name, task_id)`（`manage_models` 门控）：
  收集 measurement（经 sample→batch→execution→task_id 过滤）+
  evidence claim（workspace 范围）。每条 manifest 条目携带：
  `recordId/recordKind/hash/rightsTraining/labelKind/semantics/
  excluded/exclusionReason`。
  - **sourceClass 区分**（AT-0601-1）：`lab_measurement` vs
    `document_claim`/`inferred_suggestion`/`measured_outcome` ——
    供应商文件声明永远不会与实验室测量同标签
    （`claimed_value` ≠ `measured_value`）。
  - **训练权**：measurement → `owned`（本地生成）；claim → 经
    `source_record → import_batch → artifact.rights.training`
    解析，缺省 `unknown`。
  - **缺失/删失/失败语义保留**：`missing`（含 missingReason）、
    `below_detection`/`above_quantification`（censored + bound）、
    rejected/superseded/not-applicable 均标 `excluded`+原因，
    不静默丢弃。
  - 摘要 hash = 记录相关字段 canonical JSON 的 sha256；
    snapshot digest = 整个 manifest 的 sha256。
- `freeze`（`manage_models`）：任一未排除条目
  `rightsTraining ∉ {allowed, owned}` → `DATA_RIGHTS_UNKNOWN`
  并列出受影响 recordIds（AT-0601-2）。冻结写入
  `frozen_by/frozen_at`。
- `drift_status`：逐条重算源记录 hash →
  `{drift, changed[], missing[], snapshotImmutable: true}`。
- `prepare_run`（AT-0601-3）：必须 frozen；漂移 →
  `{ok:false, reason:"source_drift", changed, missing}` —
  签名 manifest **从不改写**；无漂移 →
  `{ok:true, digest, entryIds（未排除）, scientificStatus:
  not_validated}`。

### 3. GraphQL

- Query：`datasetSnapshots(taskId)` → `[DatasetSnapshotInfo!]!`、
  `datasetSnapshotDrift(snapshotId)` → JSON。
- Mutation 命名空间 `learning`：`snapshotBuild`、
  `snapshotFreeze`（错误经 `safeDetails.recordIds` 透出）、
  `snapshotPrepareRun`（report JSON）。
- `packages/contracts/schema.graphql` 已重导出（1185 行）。

### 4. 前端 `features/learning/datasets/`

`DatasetsPanel` 挂 TaskWorkspace 新 "datasets" tab：
- 构建表单（name + purpose 下拉）。
- 快照卡：state/digest/frozenAt 徽章、条目表（sourceClass、
  labelKind、rightsTraining 徽章、semantics JSON、
  excluded+原因）、draft → freeze 按钮（`DATA_RIGHTS_UNKNOWN`
  错误显示受影响 recordIds）、frozen → "check drift"（结果徽章）+
  "prepare run"（成功显示 eligible 计数 + digest；漂移显示
  source_drift 且注明快照不变）。
- 页首明示 fixture-only / not scientific validation。

## 已知限制 / 能力声明

- 快照条目覆盖 measurement + evidence claim；SourceChunk、
  formulation revision 等其它记录类型在后续 ticket（如
  CS-0602 split 构建器）按需纳入。
- claim 纳入是 workspace 级（claim 无 task_id）；measurement
  在提供 task_id 时按任务过滤。
- `prepare_run` 返回运行清单但**不创建训练运行** —— 训练运行
  生命周期属后续 ticket（§17.5）。
- 分组键（formula sibling/同批次/近似重复 connected components，
  §17.2 step 4）属 CS-0602 split 职责，此处不承担。
- 全部合成 fixture；快照 manifest 明示 `not_validated`。
