# CS-0104 — Build GraphQL Node and Relay foundation

**Status:** completed
**Phase:** P01 · **Owner:** api

## Changed files

Backend (`services/studio-api/src/studio/api/graphql/`):

- `ids.py` — keyset cursor codec: opaque base64 payload
  `{v, kind, scope-sig, key:(created_at,id)}`; `scope_signature()` binds
  a cursor to connection kind + workspace + filter + order via sha256.
  `decode_cursor` rejects wrong-version/-kind/-scope reuse with
  `VALIDATION` — a cursor can never be silently misapplied.
- `context.py` — `GraphQLContext` (strawberry `BaseContext` subclass):
  request, request-scoped DB session, settings, lazy `ServiceContext`
  (built once per request through `build_context`), lazy per-request
  `Loaders` bound to the workspace.
- `loaders.py` — request-scoped DataLoaders (`projects`, `tasks`,
  `principals`) that batch-load only rows in the caller's workspace.
- `connections.py` — `PageInfo`, `PageArgs`, `page_args` (bounded
  `first` 1..50, decodes+binds `after`), `reject_backward` (`before`/
  `last` → `VALIDATION`, never silently handled), `keyset_page`
  (stable `(created_at DESC, id DESC)` ordering, `first+1` probe for
  `hasNextPage` without COUNT, per-row encoded cursors).
- `types.py` — `User`, `Workspace`, `Project`, `Task` as
  `relay.Node` types with canonical GlobalIDs
  (`base64("<Type>:<uuid>")`). `resolve_nodes` runs through the shared
  `_by_ids` scoped batch lookup — foreign-workspace IDs resolve to
  `null`, indistinguishable from missing. `Task.project` resolves via
  the request-scoped projects DataLoader.
- `schema.py` — `Query` (`node`, `nodes`, `viewer`, `workspace`,
  `projects` connection, `projectTasks` connection, `researchTask`,
  `engineCapabilities`, `hardwareCapabilities`) and `Mutation`
  (`taskCreate` → `TaskCreateResult` with typed `DomainErrorPayload`
  errors, not transport failures). All resolvers delegate
  authorization to `ServiceContext.require` — never resolver-local
  checks. `graphql_app()` opens a request-scoped DB session in the
  context getter.
- `app.py` — `/graphql` wired via `include_router` (GraphQLRouter is
  an APIRouter); `close_request_db` middleware guarantees the
  request-scoped session is closed in `finally`.

## Acceptance mapping

- **AT-0104-1** (entity returned by list/mutation → `node(id)` yields
  same canonical ID/type under authorization): `node` resolves a Task
  GlobalID back to the identical base64 ID + type
  (`test_node_roundtrip_task`); `taskCreate` returns a `Task` node
  whose ID decodes to the persisted row
  (`test_task_create_returns_canonical_id`, asserts
  `GlobalID.from_id` roundtrip + DB row). Authorization is enforced by
  `ServiceContext` inside `_by_ids` — an unauthenticated `node` query
  returns GraphQL errors (`test_unauthenticated_node_query_errors`).
- **AT-0104-2** (tied creation times, several pages → no
  duplicate/missing, correct pageInfo): ordering is
  `(created_at DESC, id DESC)` with the UUID tie-breaker, so tied
  timestamps cannot duplicate or drop rows
  (`test_forward_pagination_no_duplicates` walks `endCursor` and
  asserts disjoint sets + correct `hasNextPage`). Page size bounded to
  50 (`test_page_size_bounded`); backward pagination rejected
  (`test_backward_pagination_rejected`); a cursor replayed under a
  foreign workspace session (`test_foreign_scope_cursor_rejected`) or
  against a different connection kind
  (`test_cross_connection_cursor_rejected`) is rejected with
  `VALIDATION`.
- **AT-0104-3** (no duplicate GraphQL transport or mirrored
  server-state cache): `infra/ci/check_relay_boundaries.py` is wired
  into `make contracts-check` — transport confined to
  `relay/network.ts`, single `Environment` in `relay/environment.ts`,
  no react-query/swr/apollo, no localStorage persistence of server
  state (7 files clean). Runtime side proven by
  `environment.test.ts`: one environment instance; `resetRelayEnvironment`
  drops the cache. Request-scoped DB session close proven by
  `test_request_session_closed` (factory spy: every opened session is
  closed).

## Limitations

- Mutation surface is `taskCreate` only; evidence/experiment/
  measurement/model/export mutation groups arrive with their domain
  tickets (CS-0105+, P02) — they are deliberately not stubbed.
- `nodes(ids)` resolves each ID independently; per-type batching goes
  through `_by_ids` but not a single deduplicated query per type.
- Backward pagination (`before`/`last`) is rejected by design; the UI
  paginates forward.
- `Task.project` is the only DataLoader-backed field so far; other
  N+1-prone fields adopt loaders as their types land.
- Subscriptions are not enabled (`graphql_ide=None`, no WS) — live
  updates are a later, reviewed change.
