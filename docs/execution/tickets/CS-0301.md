# CS-0301 — Build quarantined document and table ingestion

**Status:** completed
**Phase:** P03 · **Owner:** controller

## Changed files

- `workers/ingestion/` — the quarantine worker package (new write
  scope, added to the wheel + mypy/ruff paths):
  - `types.py` — `ExtractedRecord` / `ParseReport` value objects
    (picklable — they cross the subprocess boundary),
    `PARSER_VERSION = "ingestion-1.0.0"`, `QuarantineError` as a
    typed, auditable denial.
  - `limits.py` — `IngestionLimits`: input bytes, decompressed bytes,
    zip members, compression ratio, pages, cells, parse timeout
    (defaults 128 MiB / 256 MiB / 5 000 / 200× / 500 / 500 000 / 60 s).
  - `quarantine.py` — pre-parse inspection: magic-byte type
    detection (pdf/zip→xlsx|docx/json/csv/md/text), zip member +
    decompression + ratio bounds, active-content denial
    (`vbaProject.bin`, macro sheets, ActiveX members; PDF
    `/JavaScript`, `/JS`, `/Launch`). Denial happens *before* any
    parser touches the payload.
  - `parsers.py` — pure bytes → records functions. No filesystem,
    no network, no evaluation: XLSX formulas are read-only source
    text, percent-formatted cells keep their stored value +
    `percent_format_ambiguous` (never mass-fraction 5), CSV `5%`
    literals get `percent_literal_ambiguous`, `1,23` gets
    `decimal_separator_ambiguous`, bare numerics get
    `unit_unresolved`, dates `locale_date_ambiguous`. Formula cells
    read the *cached* result where one exists
    (`cached_formula_result`) and flag `missing_cached_value` +
    `untrusted_formula` where it does not — expression text always
    preserved. Merged ranges recorded per-cell; sheet/cell,
    row/col/header, page, paragraph, jsonpath locators.
  - `runner.py` — `run_parse` crosses a spawned
    `multiprocessing` subprocess with a hard timeout; a timeout is
    a real `proc.kill()`, reported as `timed_out` + `PARSE_TIMEOUT`
    finding. `isolate=False` exists for fast unit paths only.
- `services/studio-api/src/studio/domain/evidence/imports.py` —
  `ImportService`:
  - `import_artifact` — scoped artifact lookup →
    `manage_sources` capability → committed-only → `rights.extraction
    == "denied"` refused (unknown → `RIGHTS_UNKNOWN` finding,
    records stay quarantined) → **dedup on (workspace, checksum,
    parser_version)** returning the existing batch → vault read →
    quarantine + parse → `ImportBatch` + `ExtractedRecord`s with
    status `proposed`. Typed quarantine denials persist a
    `quarantined` batch with findings — auditable, zero records.
  - `document_group` + `source_revision`: same original name →
    same group, next revision; changed bytes create a new source
    revision, never overwrite.
  - `review_record` — human-only (`user` principal) accept/reject
    of proposed records; decided records conflict on re-review.
  - `quality_report` — §9.3 rollup: received/parsed/quarantined/
    failed, proposed/accepted/rejected, per-flag counts, missing
    units, ambiguous percent, rights-unknown artifacts, and
    training exclusions.
- `services/studio-api/src/studio/persistence/models.py` —
  `ImportBatch` (unique dedup constraint
  `uq_import_batches_dedup`, scoped artifact FK, `document_group`
  index) and `ExtractedRecord` (scoped batch FK, confidence
  range check, `proposed|accepted|rejected`).
- `services/studio-api/migrations/versions/0008_ingestion.py` —
  same shape in SQL; adds `uq_artifacts_scope_id` (needed by the
  scoped artifact FK — same gap class fixed in 0007) and
  `uq_import_batches_scope_id` for the records' composite FK.
- `pyproject.toml` — parser deps `openpyxl`, `python-docx`,
  `pypdf` (all ≥7 days old, bounded ranges), dev stub
  `types-openpyxl`; `workers` added to wheel/mypy/ruff scope.

## Honest status / boundaries

- No GraphQL/REST surface yet — imports are service-level (CS-0302
  wires evidence tasks).
- PDF parsing is text-layer only; scanned pages report
  `REQUIRES_OCR_REVIEW` findings, never a fabricated extraction.
- Office formats are parsed structurally — hyperlinks/scripts are
  never followed or executed; there is no parser network access by
  construction.
- `isolate=False` path exists for tests; application default is
  the subprocess boundary.
