## 实现内容

### 1. 备份/恢复 `infra/local/backup.py`（新）

- `backup --dsn --vault --out`：`pg_dump --format=custom` + vault 树
  复制 + `manifest.json`（format 版本、创建时间、**alembic head**、
  db dump sha256/bytes、每个 vault 文件 sha256/bytes）。
- `verify --backup`：仅校验清单，不写任何内容。
- `restore --backup --dsn --vault [--force]`：**先校验清单再写入**；
  vault 文件落盘后逐一复算 sha256；vault 路径逃逸（`..`）拒绝；
  已存在文件无 `--force` 不覆盖。
- 工具解析：优先宿主 `pg_dump`/`pg_restore`，缺失时回退
  `docker exec -i chem-studio-postgres`（stdin/stdout 流式 —
  容器看不到宿主路径，DSN 重写为容器内 `127.0.0.1:5432`）。
- 核心 profile **无独立密钥库**：会话/凭据哈希都在 DB dump 内，
  已在模块文档与 runbook 明示 —— 若将来引入密钥库必须先纳入
  备份覆盖才可声称恢复就绪（§21.6）。

### 2. 无出站校验 `tests/integration/recovery/no_egress_check.py`（新）

- **静态扫描**：`services/studio-api/src` 无任何可出站客户端导入
  （httpx/requests/urllib.request/http.client/aiohttp/smtplib/
  ftplib）。全仓唯一网络客户端是 `workers/inference` 的 urllib
  —— 绑定 loopback llama.cpp 容器。
- **运行时守卫**：进程级 patch `socket.connect`/`connect_ex` 仅放行
  loopback peer；在守卫下用 TestClient 跑真实 app（新建迁移 DB +
  临时 vault）：owner setup → projectCreate → projects 查询 —
  任何专有数据外发尝试直接抛 `EGRESS BLOCKED`。

### 3. 备份恢复校验 `tests/integration/recovery/backup_restore_check.py`（新）

- 在 compose PG 上建 `studio_backup_src`，migrate 至 head，植入
  fixture 行（workspace/principal/capability/project/artifact）+
  vault blob。
- 备份 → 恢复到全新 `studio_backup_dst` → 断言：
  artifact 行存活、权限行（`principal_capabilities`）存活、
  project→workspace 引用存活、vault blob 字节级一致、
  清单 sha256 与恢复后文件一致、alembic head 保持。
- `make backup-test` 现指向此脚本（原 BLOCKED 桩移除）。

### 4. 试点门报告 `infra/local/pilot_gate.py`（新）

生成 `docs/operations/pilot-gate.md`：能力矩阵显式区分
**软件状态**（live/fixture/blocked/unavailable）与
**科学验证状态**（全部 `not_validated`）。状态来源：
- 可探测项真实探测（`docker image inspect` rdkit/llama.cpp 镜像、
  `docker volume inspect chem-models`、compose PG）。
- 未实现项如实常量（BayBE/训练/RL/云/设备控制/ELN = blocked）。

### 5. 运行手册 `docs/operations/backup-restore.md`（新）

§26.3 格式：前置条件、精确命令、预期输出、失败症状表、恢复步骤、
隐私关注（备份含令牌哈希 —— 与 vault 同级保护；无应用层静态加密，
依赖 OS 卷加密；不承诺 SSD/云副本的安全擦除）。

## 已知限制 / 能力声明

- 备份加密/密钥恢复**未实现** —— 依赖 OS 卷加密；
  敏感部署的恢复就绪声明需在此之前保留（§21.6）。
- 无异地/轮换策略；不承诺 SSD 或云副本的安全擦除。
- 无独立密钥库：DB dump 即含全部认证材料 —— 备份文件需与
  vault 同级保护。
- 出站校验覆盖：核心 src 无出站客户端 + 进程内 socket 守卫；
  不证明宿主环境整体无外发（如 IDE、其他进程）。
- 保留期为配置占位，非法律排期。
