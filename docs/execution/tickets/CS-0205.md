## Limitations

- Screens in the map are `not_started` — routes land in CS-0206.
- Components are styled to the token sheet, not to a supplied
  visual design (none exists — this is specification-faithful, not
  a parity claim).
- Organisms from §22.3 (ContractEditor, FormulationEditor,
  CandidateDiff, …) compose these molecules with task data in
  CS-0206+; they're listed in the workplan, not yet built.
- `DevComponents` is a dev-only route; it is unlinked and renders
  without backend access.
- e2e runs against `vite preview` of a production build; backend-
  dependent journeys (auth'd flows) arrive with CS-0206.
