## 实现内容

### 1. `workers/optimization/property_models/` — 纯 stdlib 属性模型（核心不进 torch/numpy）

- `transforms.py`：`FeatureSpec` + `FeatureVectorizer` 实现 CS-0602 的
  `SplitTransform` 协议 —— 中位数/均值/方差/类别词表/训练值域
  **仅在 fit 分区上学习**；数值缺失 → 训练均值（缩放后 0），未知类别 →
  全零向量并标记 `unknown_category`；常数/从未观测特征如实声明为
  `unusable_features`，绝不静默丢弃。
- `linear.py`：`RidgeRegressor` —— 正规方程 + Gauss-Jordan 部分主元；
  λ=0 或退化设计矩阵直接 `ValueError`，无伪解。
- `applicability.py`：`ApplicabilityAssessor` —— 双层判定：
  **训练值域**（未知类别/非数值/超出训练范围 → `out_of_domain`）+
  **数据驱动稀疏度**（阈值 = 训练集最近邻距离最大值，dist > 阈值 →
  `sparse`）。不发明任何科学阈值。
- `calibration.py`：`SplitConformalCalibrator` —— 分裂共形绝对残差；
  分位数 `ceil((n+1)·coverage)`，仅在 `calibration` 分区拟合；
  报告如实声明 exchangeability 假设与非 OOD 保证。
- `predictor.py`：`PropertyPredictor` 组合上述；`fit` 经
  `fit_transform(allowed=("train",))` —— 预处理永远不碰全量数据；
  OOD 行不发校准区间（`interval=None`）；`manifest()` 发布
  scope/trainingCoverage/missingValuePolicy/calibration/applicability/
  limitations，`scientificStatus="not_validated"`。
- `evaluation.py`：`evaluate_property_model` —— AT-0604-1 的
  **同例同预算**比较：ridge / ridge_in_domain / mean / median 全部
  打分在同一 `final` 分区同一示例集上，MAE/RMSE/小样本声明；
  `denominator_report` 让无标签/缺特征/OOD 行计入 missing/invalid，
  绝不消失。
- `readiness.py`：`assess_readiness` —— 结构性门槛 only：
  labeled ≥ 调用方声明下限、≥2 个 lineage group（否则留出集不可能存在）、
  `final` 分区非空。输出 `not_ready|ready|fixture_ready` +
  coverage + 真实 exclusion 计数 + blockers。

### 2. `packages/engine-adapters/chemprop/` — 有界版本化适配器（torch 不进核心）

- `contracts.py`：`TrainSpec`（1..20000 行、seed、max_epochs≤300、
  ensemble≤8、`context` 必填有界元数据、`digest()` 内容寻址）/
  `PredictSpec`（≤512 行、64-hex `model_digest`；**预测行无 label 字段**）；
  `TrainResult`/`PredictResult` 固定 `pretrained=False`、
  `scientific_status∈{fixture_only,not_validated}`、
  `engine_version="2.3.1"`、`adapter_version="chemprop-adapter/v1"`；
  `extra="forbid"` 拒绝一切未声明字段（pretrained/hyperopt/未知 representation）。
- `validation.py`：`check_smiles` 结构检查（化学解析归容器内 RDKit）；
  `model_file_digest` = sha256(spec_digest + 每个文件哈希) —— 血统绑定；
  `validate_predictions` 对引擎**不可信输出**独立校验（成员数=声明
  ensemble、有限值、无重复、行归属请求集），非合规行拒绝不修复。
- `adapter.py`：容器内运行 —— `MoleculeDatapoint.from_smi` +
  `BondMessagePassing(d_h=hidden_dim)` + `RegressionFFN(input_dim=
  hidden_dim)` + split-conformal 外无关的 ensemble variance；
  `normalize_targets` + `UnscaleTransform`；`models.save_model` 产物 +
  `manifest.json`（记录训练 spec_digest + scope）。predict 时先重算
  `model_file_digest` 对 `spec.model_digest` —— 外源/篡改/缺 manifest 的
  工件一律拒绝。fail-closed：不可 featurize 的行/加载失败/行数不符 →
  `ENGINE_UNSUPPORTED_INPUT|ENGINE_UNAVAILABLE`，无伪预测。

### 3. `workers/optimization/property_models/chemprop/` — 隔离运行器（镜像 BayBE 模式）

- `runner.py`：`request.json` ≤2MB → train/predict → stdout 单行 JSON；
  `{error,message}` 退出码 2，引擎 traceback/SMILES 不出容器。
- `runtime.py`：`IsolatedChemprop` 跑
  `chem-studio-chemprop:2.3.1-v1`（`--network none`、只读根、
  非 root、600s/6GB/256 进程上限、2MB 输出/256MB 文件）；
  `available()` 只探测镜像不假设；训练返回
  `(TrainResult, 文件字节, isolation)`，工件集合必须与 `model_files`
  完全一致否则拒绝。
- `Dockerfile`：`python:3.12.14-slim` + `libxrender1/libxext6/libexpat1`
  （rdkit/cuik 轮子需要）+ `requirements.lock` 62 个精确钉住
  （chemprop==2.3.1, torch==2.14.1+cpu, lightning==2.6.6, rdkit==2026.3.6…）；
  仅 COPY adapter 目录 + `workers/__init__.py` + runner.py，
  中间包走 namespace package —— property_models 的重量级
  `__init__`（import studio 模块）故意不进镜像。

### 4. `services/studio-api/src/studio/domain/learning/property_models.py` — 就绪判定

- `PropertyModelService.readiness(snapshot_id, target, min_labeled_examples,
  seed)`：CAP_MANAGE_MODELS 门控；`DatasetService.prepare_run` 前置 —
  未冻结 → `not_ready`+`snapshot_not_frozen`；漂移 → `not_ready`+
  `source_drift`+changed/missing；通过的 manifest 逐条映射为带
  `sample/batch/execution` 三层 lineage key 的 `SplitRecord`；
  `exclusionReason`/`source_class:claim`/`target_mismatch`/
  `non_finite_label`/`source_missing` 如实计数；
  结果含 snapshotId/digest/scope/`snapshotImmutable`。
  **数据不足永远返回 capability 报告，绝不返回训练好的预测器。**

## 已知限制 / 能力声明

- **capability 标注**：`PropertyPredictor.manifest().scientificStatus =
  "not_validated"`；evaluate 报告 `scientificStatus="fixture_only"`；
  Chemprop `TrainResult.pretrained=false` 且 `scientific_status` 只允许
  `fixture_only|not_validated`。合成数据无科学效度声明；未知科学阈值
  一律保持为 promotion blocker（未发明最小样本数/精度线）。
- 适用性判定 = 训练值域 + 数据驱动稀疏度；OOD 行仍可进入探索性
  审视但无校准区间、不计为已验证排名（`ridge_in_domain` 单独报告）。
- Chemprop ensemble variance 是引擎级分歧信号，**不是**校准区间；
  校准只在 property_models 层做 split-conformal。
- Chemprop 仅在隔离容器运行；核心不 import torch/lightning/numpy；
  镜像缺失时 engine 测试**显式 skip**（本次镜像已构建并实测全过）。
- 引擎测试依赖本机 docker + `chem-studio-chemprop:2.3.1-v1` 镜像。
