## 实现内容（按 ticket 顺序）

### 1. 许可/模型/输入种类先验（U13 — 先于一切下载与运行）

- `engine_adapter_{reinvent,aizynthfinder}/contracts.py`：
  纯 pydantic（`extra="forbid"`，frozen），无科学库 import ——
  宿主进程在无 torch/rdkit 环境下即可做结构校验与许可门（E05）。
  `ModelAsset{name,version,license,source,sha256}` 承载声明式
  provenance；`SUPPORTED_INPUT_KINDS=("small_molecule_smiles",)`
  与 `ALLOWED_MODEL_LICENSES={apache-2.0, mit, cc-by-4.0,
  bsd-3-clause}` 固定写死。
- `validation.py`：**已评审资产登记表**（registry）——
  - reinvent: `reinvent_pubchem`（Zenodo 20701824, Apache-2.0,
    sha256 fe8cd167…9ef3，镜像内 `/opt/models/`）
  - aizynthfinder: `uspto_expansion` + `uspto_filter`（Zenodo
    7797465, CC-BY-4.0）、`uspto_templates`（Zenodo 7341155,
    CC-BY-4.0）、`zinc_stock`（figshare 23086469, MIT）
  `check_model_license`/`check_asset_license` 先查 license 白名单，
  再对登记表做 name+version+license+sha256 全等匹配 ——
  未登记、license 不在白名单、或 hash 不符一律 `LICENSE_UNAVAILABLE`
  （先于任何运行尝试）。`check_input_kind` 对非
  `small_molecule_smiles` kind 抛 `ENGINE_UNSUPPORTED_INPUT`。
- `compute()` 内部重放同一组门（容器侧权威，持久化字节为凭）+
  镜像内 baked 文件 sha256 实测比对 —— 双重防线：声明对不上
  registry 或文件对不上声明都拒。

### 2. 产出接 structural/gate/evidence 检查（全部 `proposed`）

- `workers/chemistry/design/` + `workers/chemistry/synthesis/`：
  与 materials/quantum 同构的隔离 worker —— `Dockerfile`（构建期
  curl+sha256sum 校验烘焙模型资产，运行期 `--network none`
  只读 root、`cap-drop ALL`、非 root uid、资源有界）、
  `runner.py`（stdin `request.json` ≤2MB → stdout JSON；
  `EngineFailure`→`{error:code,message}` exit 2；`--capability`
  探针）、`runtime.py`（`IsolatedDesign`/`IsolatedSynthesis` —
  `ContainerBackend` + `ExecLimits`，`RUN_CANCELLED`/`RUN_TIMEOUT`
  映射回宿主语义）、`requirements.lock`（pip freeze 全量冻结 —
  reinvent 按 git tag v4.8 解析的 commit `80a8d21` 钉死）。
- `services/studio-api/src/studio/domain/chemistry/{design,synthesis}.py`：
  `DesignService`/`SynthesisService` —— 与 MaterialsService 同型：
  profile gate → kind 预检 + `model_validate` → `build_job_payload`
  → 输入 artifact 落 vault（`source_kind="derived"`，工作区级私有）
  → `runs.request` → `available()` 否则 `runs.block`
  (`engine_not_installed`/`not_installed`) → `admission.admit`；
  `execute()` 从持久化字节重建 spec（payload/spec 漂移检查在
  容器内重放）→ 结果 artifact + `complete_attempt`/
  `fail_attempt`/`confirm_cancelled`/`timeout_attempt`。
  请求校验失败的 run 以 `blocked` + `capability=unsupported |
  license_unavailable | insufficient_inputs` 记账，不产生 artifact/
  attempt。
- 结果合同：`DesignOutcome`/`RouteOutcome` 恒 `label="proposed"`、
  `scientific_status="not_validated"`、`execution_gate=
  "independent_plan_approval_required"`、`does_not_establish`
  结构化字段（设计：活性/可合成性/安全/新颖性/任何实验性质；
  路线：yield/selectivity/safety/scale_up/cost/实际可购性）+
  `provenance`（模型+stock+版本+hash+anchor/target digest）。

### 3. 合成计划保持假设，需人工评审（AT-0903-3）

- `ProposedRoute.is_solved`/`all_precursors_in_stock` 如实透传
  stock 命中 —— 但 `evaluate_execution(outcome)` 恒返回
  `executable=False` + `verdict="independent_plan_approval_required"`
  + `basis="proposed_route_is_hypothesis"`：stock 命中不是
  yield/选择性/安全/放大 的证据，路线永不自动发布为实验协议。
  `SynthesisService.assess_execution` 暴露该 verdict 供上游使用。
- 安全测试落地：stock 全部命中的路线包装进 `ExperimentPlan` 后，
  agent principal 调 `review` 仍 `FORBIDDEN`（`effective_grants`
  已在主体层剥掉 `approve_experiment`）；researcher 同样无权 ——
  只有 `scientific_reviewer` 能 approve，且 `missing_method`
  blocker 等 §21.5 未知输入仍照常拦截。

## 已知限制 / 能力声明（§16.1 对齐）

- **capability 如实上报**：镜像缺失 → `not_installed`（integration
  用真实 `available()` 判定，不 mock）；profile 关 → `disabled`；
  资产 hash/license 不过 → `license_unavailable`/`installed_unverified`。
  无任何「假装验证过」的路径 —— fixture 输入标 `fixture_only`，
  结果恒 `scientific_status="not_validated"`。
- **reinvent 版本口径**：上游 v4.8 tag 安装后 dist 报告
  `4.8.24`——版本门按 4.8 发布线匹配（`_version_line_ok`），
  `engine_version` 回显真实值。
- **宿主不装重依赖**：reinvent/aizynthfinder/torch/onnxruntime/
  rdkit 只在容器内（requirements.lock 冻结），宿主侧 mypy 用
  `ignore_missing_imports` + adapter 懒加载 —— 与 qcengine/
  materials 的既有取舍一致。
- **scipy 未声明但必需**：reinvent@4.8 的
  `runmodes.samplers.reports` 导入链无条件 `import scipy`
  （上游未列进 dependencies）——已在锁文件中显式钉 scipy 1.18.1。
- **rdkit X11 依赖**：两镜像均需 `libxrender1`/`libxext6`
  （`rdkit.Chem.Draw` 导入链拉 X11，即使不画图）。
- **aizynthfinder 内存包络**：stock+ONNX 全量常驻内存，4096MB
  不足（实测 exit 137 OOM）——基准资源按 8192MB 上限跑通；
  contract 上限 `MAX_MEMORY_MEBIBYTES=8192` 与之一致。
- **执行权永不授予**：路线（哪怕全部 stock 命中）只是假设 ——
  `execution_gate` 结构性固定；agent/researcher 均无
  `approve_experiment`；`evaluate_execution` 恒 `executable=False`。
- **未做**（明确出界）：CS-0506（U16）、P10+；reinvent 的
  scoring/optimization run_type（本票只钉 de novo sampling
  一个方法卡）；GPU 路径（全 CPU）；RL 环境接线（CS-0902 域）。
