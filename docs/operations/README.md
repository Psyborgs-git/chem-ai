# Operations manuals

These guides describe the local, single-workspace deployment. Begin with
installation; add optional providers, workers, or simulations only when needed.
No paid inference call is required to set up or use the core Studio.

| Manual | Use it for |
|---|---|
| [Installation](installation.md) | Dependencies, PostgreSQL, startup, owner setup, and first calculation |
| [Configuration and stored state](configuration.md) | Active ports, settings, vaults, Downloads, model files, credentials, and backup coverage |
| [Administration](admin.md) | Access, background processes, jobs, incidents, and dependency changes |
| [Troubleshooting](troubleshooting.md) | Startup, sign-in, conflicts, providers, workers, and storage failures |
| [Native macOS app](desktop-macos.md) | Build, open, runtime ownership, logs, and packaging limits |
| [Inference providers](inference-providers.md) | Connections, models, consent, secure keys, and cleanup |
| [Agent and private library](agentic-research.md) | Private context, retained sources, recurring work, and background service |
| [Private learning workspace](learning-workspace.md) | Datasets, optional runtimes, jobs, evaluation, and worker protocol |
| [Scientific workflows](scientific.md) | Plans, manual results, measurement corrections, closeout, and adapters |
| [Engine and model operations](model-ops.md) | Optional engine images, isolation, older model registry, and promotion |
| [Polymer simulations](polymer-simulation.md) | Native runtime, capped repeat units, pilots, artifacts, and resumption |
| [Privacy and disclosure](privacy.md) | Private records, provider sends, export review, revocation, and retention |
| [Backup and restore](backup-restore.md) | Consistent database/vault snapshots, verification, and clean-target restore |
| [Recovery and upgrades](recovery.md) | Interrupted work, migrations, backfills, and recovery checks |
| [Confidential cloud posture](cloud-security.md) | Implemented adapter boundary and prerequisites for a future live provider |
| [External ELN bridge](eln.md) | Optional eLabFTW adapter, record ownership, and integration limitations |
| [Studio usage](user.md) | Entry point to the current end-user manuals |

The [documentation home](../README.md) separates current manuals from historical
specifications, pilot reports, and verification records. The generated
[reference index](../reference/README.md) inventories interfaces and environment
settings; manual examples explain how to use them.
